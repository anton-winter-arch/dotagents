# tidelog (linked docs-and-code test fixture)

A small tide gauge logger with its docs in `docs/`, used by the tests that link the markdown-kg and code-kg graphs.
All content is invented.

Start with the [operating guide](docs/guide.md).
The command line entry is [cli.py](src/tidelog/cli.py), and an outage is repaired with [backfill.sh](scripts/backfill.sh).
